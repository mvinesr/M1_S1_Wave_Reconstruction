# Data

This directory documents the third-party offshore source data required by the reconstruction workflow and contains the model-derived reconstructed M1 output series generated by the deep-learning models.

## Model input

The original Puertos del Estado source time series are **not included in this repository** and should not be redistributed through the public GitHub/Zenodo release. Users must obtain the corresponding data independently from the Puertos del Estado Portus historical-data service.

Source portal: https://portus.puertos.es/#/

The workflow requires the following two source datasets:

| Expected local file | Manuscript ID | Source | PdE identifier | Main raw columns | Date format |
| --- | --- | --- | --- | --- | --- |
| `model_input/Wave_data_offshore_M1.csv` | M1 | Bilbao-Vizcaya deep-water buoy, REDEXT | Buoy code **2136** | Fecha; Hs; Tp; Dir | DD/MM/YYYY HH:MM |
| `model_input/reference_SIMAR_data.csv` | S1 | SIMAR offshore point, AIB grid | SIMAR code **3155039** | Fecha; Hs; Periodo Medio(s); Tp; Direcc. Media de Proced.(0=N,90=E) | YYYY MM DD HH |

### Source metadata

**M1 — Bilbao-Vizcaya buoy**

- Provider: Puertos del Estado.
- Network/dataset: REDEXT.
- Buoy code: **2136**.
- Position: **43.63° N, 3.03° W**.
- Water depth: **580 m**.
- Native sampling interval: **60 min**.
- Start of measurements reported by Portus: **7 November 1990**.

**S1 — SIMAR point**

- Provider: Puertos del Estado.
- SIMAR code: **3155039**.
- Position: **43.63° N, 3.04° W**.
- Grid: **AIB**.
- Native sampling interval: **60 min**.
- This point corresponds to **S1** in the manuscript.

The notebook uses `Fecha` and `Hs`, interpreting `Hs` in metres, and subsequently resamples the model workflow to three-hour intervals. Users should verify the time reference/time zone, remaining variable definitions, units, direction convention and missing-value codes against the metadata supplied with their own download.

### Redistribution and attribution

Puertos del Estado states in its Oceanography FAQ that downloaded data may be used for the specific purpose of the download, that Puertos del Estado must be duly acknowledged as the source, and that transfer of the downloaded data to third parties is not permitted.

Accordingly, the raw M1 and SIMAR files are intentionally excluded from this repository and from the public archived release. Each user must download the required source series directly from Puertos del Estado and use them under the conditions applicable to that download.

Current provider information and terms:

- Portus: https://portus.puertos.es/#/
- Oceanography FAQ: https://www.puertos.es/servicios/oceanografia/faqs

The software's MIT licence does not grant or modify rights over Puertos del Estado source data.

## Model output

The `model_output/` directory contains the reconstructed significant wave height (`Hs`) series at the M1 buoy location produced by the three deep-learning architectures evaluated in the study:

| File | Model | Description |
| --- | --- | --- |
| `model_output/M1_reconstructed_CNN_GRU.csv` | CNN-GRU | Reconstructed M1 `Hs` time series |
| `model_output/M1_reconstructed_TCN.csv` | TCN | Reconstructed M1 `Hs` time series |
| `model_output/M1_reconstructed_ConvLSTM.csv` | ConvLSTM | Reconstructed M1 `Hs` time series |

These files are model-derived reconstructions rather than direct observations or copies of the original Puertos del Estado source series. They are included to facilitate reproducibility, comparison among architectures and downstream analysis of the reconstructed offshore wave record.

No nearshore observations, reconstructed nearshore series or nearshore SWAN outputs are included in this repository. The model outputs provided here correspond only to the offshore M1 reconstruction used in the study.
